# 🏝️ Island — Dynamic Island для Windows

Островок как на iPhone, но на рабочем столе Windows. Прозрачная капсула поверх всего, раскрывается при наведении.

## Что умеет (v1.4.0)

**Мониторинг**
- CPU, GPU (нагрузка + температура NVIDIA), RAM, диск
- FPS в играх через PresentMon (с 1% low)
- Сеть: скорость скачивания/отдачи
- Топ процессов по CPU с завершением в один клик

**Медиа**
- Плеер всего, что играет в системе: музыка и видео в любом приложении и браузере
- Обложка трека: из системы или автоматически из интернета (iTunes)
- Управление: play/pause, треки, громкость (включая колесо мыши)

**Инструменты**
- 🌐 Переводчик: авто ru↔en + EN/DE/FR/ES/UA/IT, перевод из буфера
- 🌤 Погода: выбор города поиском или по IP
- 💵 Курсы валют ЦБ РФ ($ и €)
- 📅 Календарь на вкладке «Часы»
- ⏱ Таймер и часы
- Центр управления: Wi-Fi, Bluetooth, яркость, скриншот, сон/выключение/перезагрузка
- Заметки, история буфера обмена, запуск приложений (Discord, Steam, Epic, Яндекс, Happ и своих)

**Внешний вид**
- 13 тем, свои цвета по каждому элементу, градиенты
- Прозрачность, размытие, скругления, скорость анимации
- Свечение под музыку, цвета из обложки, пластинка вместо обложки
- Перетаскивание по экрану, автозапуск с Windows, Ctrl+Alt+I — закрепить

## Запуск из исходников

Нужен [Node.js](https://nodejs.org):

```
npm install
npm start
```

Без окна терминала: двойной клик по `start-island.vbs`.

## Сборка установщика

Двойной клик по `build-installer.bat` — в папке `dist` появятся `Island-Setup.exe` и `Island-Portable.exe`. Node.js другу не нужен.
