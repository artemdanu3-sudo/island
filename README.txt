КАК ПОДЕЛИТЬСЯ С ДРУГОМ (самый простой способ)
  1. Двойной клик по build-installer.bat (один раз, нужен интернет).
  2. В папке dist появятся два файла:
       Island-Setup.exe     - установщик (появится в меню Пуск)
       Island-Portable.exe  - запускается без установки
  3. Отправь другу любой из них (Telegram, Google Диск, флешка). Node.js другу не нужен.
  Windows может показать "Windows защитила ваш компьютер": нажми "Подробнее" -> "Выполнить в любом случае".
  Так бывает со всеми программами без платной подписи.

ЕСЛИ У ДРУГА УЖЕ ЕСТЬ ИСХОДНИКИ (island-source.zip)
  Распаковать архив и запустить install-and-run.bat. Нужен Node.js.

ДЛЯ СЕБЯ
  npm install, затем npm start (или start-island.vbs без окна терминала).
  Автозапуск: остров -> настройки -> "Запускать с Windows".
